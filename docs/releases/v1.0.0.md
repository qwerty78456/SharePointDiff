# SharePoint Diff v1.0.0

## Tiếng Việt

Ứng dụng Windows WPF để đối chiếu thư mục local với SharePoint Online bằng hash, tải các tệp thiếu và thay tệp khác biệt theo lựa chọn, có sao lưu trước khi ghi đè.

**Yêu cầu:** Windows x64 và **.NET 10 Windows Desktop Runtime**. Đây là gói dùng runtime có sẵn, không bao gồm runtime. Không cần Python, PowerShell hoặc Visual Studio khi sử dụng.

1. Tải `SharePointDiff-1.0.0-win-x64.zip`, giải nén toàn bộ rồi mở `SharePointDiff.exe`.
2. Đọc `README.md` để cấu hình hồ sơ Entra ID, quyền đọc và đường dẫn.
3. Tuỳ chọn: kiểm tra ZIP theo `SHA256SUMS.txt` bằng `Get-FileHash -Algorithm SHA256`.

- Chuyển ngôn ngữ Việt–Anh ngay trong giao diện; bảng có ảo hoá cho hàng nghìn tệp.
- Quét bằng dung lượng và QuickXorHash; bước so sánh không tải nội dung SharePoint.
- Tái dùng bản cùng hash ở local/cache; tối đa hai lượt tải, hỗ trợ tiếp tục khi máy chủ cho phép.
- Ba chế độ ghi đè; bắt buộc sao lưu và kiểm tra SHA-256 trước khi thay tệp. Tệp chỉ có ở local được để nguyên.
- Metadata JSON/CSV riêng, báo cáo từng tệp và đường dẫn sao lưu.
- Lỗi hiển thị nguyên nhân, thao tác, tài nguyên và stack trace; lỗi lập trình dừng tác vụ và thoát mã `1`.

Kiểm chứng: **43/43 kiểm thử**, dữ liệu giao diện giả lập **10.000 tệp**; kiểm tra site thật chỉ đọc danh sách và metadata, không tải nội dung và không ghi lên SharePoint. Xem `docs/Verification.md` để biết phạm vi và giới hạn. Thử ghi đè trên thư mục sao chép riêng trước khi dùng với một bộ tài liệu mới.

Phạm vi v1: SharePoint Online thương mại, phiên bản tệp hiện hành; không đồng bộ ngược, lịch sử phiên bản hoặc quyền.

## English

A Windows WPF app that compares local files with SharePoint Online using hashes, downloads selected missing files and replaces selected differences with verified backups.

**Requirements:** Windows x64 and **.NET 10 Windows Desktop Runtime**. This framework-dependent package does not bundle the runtime. Python, PowerShell and Visual Studio are not required at runtime.

1. Download `SharePointDiff-1.0.0-win-x64.zip`, extract all files and launch `SharePointDiff.exe`.
2. Follow `README.md` to configure the Entra profile, read permissions and local folder.
3. Optionally verify the ZIP against `SHA256SUMS.txt` using `Get-FileHash -Algorithm SHA256`.

Includes live Vietnamese/English switching, a virtualized file table, QuickXorHash comparison without content downloads, local/cache reuse, controlled replacement modes, mandatory SHA-256-verified backups, typed metadata exports and detailed diagnostics. Local-only files are preserved. SharePoint is read-only.

Validation: **43/43 tests passed**, a **10,000-file** synthetic UI dataset, and read-only live inventory/metadata verification with zero content downloads or remote writes. See `docs/Verification.md` for coverage and limitations. Validate replacement using a separate test copy first.

Version 1 supports commercial SharePoint Online and current file versions; no reverse sync, version history or permission synchronization.
