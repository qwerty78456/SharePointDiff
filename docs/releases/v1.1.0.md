# SharePoint Diff v1.1.0

## Tiếng Việt

Bản này thêm **kiểm tra khi đăng nhập Windows**: biểu tượng ở khay hệ thống quét nền sau khi bạn đăng nhập, rồi hỏi trước khi tải về. Bản này cũng làm việc tải bền hơn khi mạng chập chờn.

**Yêu cầu:** Windows x64 và **.NET 10 Windows Desktop Runtime** (không đóng gói kèm). Không cần quyền admin, không cài Windows Service.

1. Tải `SharePointDiff-1.1.0-win-x64.zip`. Bấm chuột phải > Properties > **Unblock** rồi giải nén vào một thư mục cố định, ví dụ `%LOCALAPPDATA%\Programs\SharePointDiff`.
2. **Gỡ hoặc xoá các bản v1.0 trước.** v1.0 không lấy khoá thư mục, nên có thể chạy chồng lên agent mới.
3. Dùng một ứng dụng Entra **chỉ đọc** (Graph `Sites.Read.All`, SharePoint `AllSites.Read`); xem `README.md` mục 2.
4. Kết nối, **So sánh** một lần cho site và thư mục, rồi bật **Kiểm tra thay đổi khi đăng nhập Windows**.

Thay đổi:

- **Agent khay** (`--agent`), khởi động qua mục Run của người dùng.
  - Quét nền ưu tiên thấp, chỉ các thư viện đã chọn ở lần So sánh gần nhất.
  - Thẻ thông báo nêu tệp mới, tệp cập nhật và các tệp khác bản đồng bộ lần trước.
  - **Đồng bộ** tải mọi tệp thiếu và thay mọi tệp khác biệt, luôn sao lưu trước. **Chi tiết** mở cửa sổ chính ở chế độ Không ghi đè. **Để sau** không làm gì.
  - Không ghi gì trước khi bạn bấm Đồng bộ. Trình duyệt chỉ mở khi bạn bấm Đăng nhập.
- **Lưu phiên đăng nhập** mã hoá DPAPI theo tài khoản Windows, kèm nút **Quên đăng nhập**. Chỉ lưu khi mọi quyền trong token là quyền đọc đã biết; mọi quyền khác (ghi, `Sites.Selected`) khiến phiên chỉ nằm trong bộ nhớ (`WriteScopedApp`).
- **Tải bền:**
  - phát hiện treo sau 60 giây;
  - tự tải tiếp bằng Range với URL mới, tối đa 8 lần;
  - sửa metadata không làm mất phần đã tải;
  - `results.csv` có cột `Attempts`/`Stalls`.
- **Sao lưu xoay vòng:** mỗi tệp giữ 3 phiên bản SharePoint gần nhất. Bản sao lưu chứa chỉnh sửa local được giữ vĩnh viễn. Cache của phiên bản đã bị thay được dọn. Mọi lần xoá đều có `prune-plan.json`/`pruned.json`.
- **An toàn:**
  - khoá thư mục `mirror.lock` (`WorkspaceBusy`);
  - đăng nhập hỏng làm dừng lượt So sánh thay vì băm toàn bộ;
  - hết thời gian chờ báo là lỗi (`RequestTimeout`), không phải huỷ;
  - tệp tạm còn sót được báo (`StaleInstallTemp`);
  - So sánh chỉ đọc thư mục của thư viện đã chọn.
- **Thay đổi bố cục dữ liệu:** bản ghi sao lưu nằm ở `runs/<run>/backup-meta/`. Thêm `library-selection.json`, `backup-sequence.json` và `mirror.lock`. Sao lưu v1.0 (có `.metadata.json` cạnh tệp) được giữ nguyên.

Kiểm chứng:
- **136/136 kiểm thử tự động**, chạy offline với HTTP và đồng hồ giả.
- 4 lượt smoke `--demo` đạt: cửa sổ chính, agent khay, hai lượt lỗi fatal.
- Thử thủ công trên site TEST với tài khoản thật **chưa được thực hiện** trong bản kiểm chứng này.

Xem `docs/Verification.md`.

## English

This release adds **checking at Windows sign-in**: a tray icon scans in the background after you sign in, then asks before downloading anything. Downloads are also more robust on unreliable connections.

**Requirements:** Windows x64 and the **.NET 10 Windows Desktop Runtime** (not bundled). No admin rights and no Windows service.

1. Download `SharePointDiff-1.1.0-win-x64.zip`, **Unblock** it (Properties), and extract it to a stable folder such as `%LOCALAPPDATA%\Programs\SharePointDiff`.
2. **Remove v1.0 copies first.** They ignore the new folder lock.
3. Use a **read-only** Entra app (Graph `Sites.Read.All`, SharePoint `AllSites.Read`); see `README.md`.
4. Connect, click **Compare** once for the site and folder, then tick **Check for changes when I sign in to Windows**.

Changes:

- **Tray agent** (`--agent`), started from the per-user Run entry.
  - Scans in the background at low priority, only the libraries ticked at the last Compare.
  - Its card lists new and updated files and those that differ from the last synced copy.
  - **Sync** downloads every missing file and replaces every difference, always after a verified backup. **Details** opens Keep-local mode. **Later** does nothing.
  - Nothing is written before you click Sync. The browser opens only when you click Sign in.
- **Saved sign-in**, encrypted with DPAPI for the current Windows user, with **Forget sign-in**. A sign-in is stored only when every scope is a known read-only one; anything else (write scopes, `Sites.Selected`) stays in memory (`WriteScopedApp`).
- **Resilient downloads:**
  - 60 s stall detection;
  - automatic Range resume with a fresh URL, up to 8 attempts;
  - partial downloads survive metadata-only edits;
  - `Attempts`/`Stalls` columns in `results.csv`.
- **Backup retention:** the 3 newest SharePoint versions are kept per file; backups of local edits are kept forever; superseded cache entries are removed. Every deletion is recorded in `prune-plan.json`/`pruned.json`.
- **Safety:**
  - folder lock `mirror.lock` (`WorkspaceBusy`);
  - sign-in failures stop a Compare instead of hashing everything;
  - timeouts are errors (`RequestTimeout`), not cancellations;
  - stale install temps are reported (`StaleInstallTemp`);
  - Compare reads only the selected library folders.
- **Data layout:** backup records moved to `runs/<run>/backup-meta/`. New `library-selection.json`, `backup-sequence.json` and `mirror.lock`. v1.0 backups (with their adjacent `.metadata.json`) are left untouched.

Validation:
- **136/136 automated tests**, offline with simulated HTTP and a fake clock.
- All 4 `--demo` smoke runs passed: main window, tray agent and both fatal checks.
- The manual end-to-end test on the TEST site with a real account has **not been run** for this verification.

See `docs/Verification.md`.
